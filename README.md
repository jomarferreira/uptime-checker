# 🌐 Uptime Checker

## 🇧🇷 Descrição
Aplicação desenvolvida em Python para monitoramento de disponibilidade de sites, permitindo verificar se um serviço está online ou offline em tempo real.

O **Uptime Checker** simula uma ferramenta simples de monitoramento, muito utilizada para verificar a disponibilidade de aplicações e serviços web.

---

## 🇺🇸 Description
A Python application designed to monitor website availability, allowing real-time verification of whether a service is online or offline.

**Uptime Checker** simulates a simple monitoring tool used to check the availability of web applications and services.

---

## 🚀 Funcionalidades | Features
- Verificação de status de sites (HTTP requests)  
- Identificação de sites online/offline  
- Interface interativa via terminal (CLI)  
- Limpeza de tela para melhor visualização  
- Tratamento de erros para URLs inválidas  

---

## 🧠 Tecnologias utilizadas | Tech Stack
- Python  
- Requests  

---

## 📦 Pré-requisitos | Requirements
Antes de executar, instale as dependências:
```bash
pip install -r requirements.txt
```

---

## ▶️ Como executar | How to run
```bash
git clone https://github.com/jomarferreira/uptime-checker.git
cd uptime-checker
pip install -r requirements.txt
python main.py
```
