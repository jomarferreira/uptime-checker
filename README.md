# 🌐 Uptime Checker

## 🇧🇷 Descrição
Aplicação desenvolvida em Python para monitoramento de disponibilidade de sites, permitindo verificar se um serviço está online ou offline em tempo real.

O **Uptime Checker** simula uma ferramenta simples de monitoramento de uptime, muito utilizada em ambientes de produção para garantir a disponibilidade de aplicações e serviços web.

---

## 🇺🇸 Description
A Python application designed to monitor website availability, allowing real-time verification of whether a service is online or offline.

**Uptime Checker** simulates a simple uptime monitoring tool, commonly used in production environments to ensure application and service availability.

---

## 🚀 Funcionalidades | Features
- Verificação de status de sites (HTTP requests)
- Identificação de sites online/offline
- Execução via terminal (CLI)
- Limpeza de tela para melhor experiência no terminal
- Tratamento de erros para URLs inválidas

---

## 🧠 Tecnologias utilizadas | Tech Stack
- Python
- Requests
